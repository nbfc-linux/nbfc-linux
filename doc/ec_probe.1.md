# NAME

ec_probe - probing tool for the embedded controller

# DESCRIPTION

Probing tool for the embedded controller

# SYNOPSIS

**ec_probe** {**read** \| **write** \| **read_bit** \| **write_bit** \|
**probe** \| **dump** \| **monitor** \| **evaluate** \| **watch** \|
**acpi_call** \| **graph** \| **lua** \| **shell**} \[*OPTIONS*\]

# OPTIONS

**-h**, **\--help**

> Show help message and exit.

**\--version**

> Show program\'s version number and exit.

**-e**, **\--embedded-controller**={**ec_sys**,**acpi_ec**,**dev_port**}

> Select the implementation used to access the embedded controller.
>
> - **ec_sys**: Use the ec_sys kernel module.
>
> - **acpi_ec**: Use the acpi_ec kernel module.
>
> - **dev_port**: Access the embedded controller via /dev/port.

# COMMANDS

**dump** \[*OPTIONS*\]

> Dump all EC registers.
>
> See **EXAMPLES** for sample output.
>
> **-c**, **\--color**
>
> > Force colored output.
>
> **-C**, **\--no-color**
>
> > Disable colored output.

**read** \[*OPTIONS*\] *REGISTER*

> Reads *REGISTER* from the embedded controller and prints out the
> value.
>
> **-w**, **\--word**
>
> > If given, the value of *REGISTER* and the value of *REGISTER + 1* is
> > read and combined into a single value.
>
> **-f**, **\--format** *FORMAT*
>
> > Specify output format of value.
> >
> > - **b**, **B**: Print value in binary.
> >
> > - **d**, **D**: Print value in decimal.
> >
> > - **x**, **X**: Print value in hexadecimal.
>
> **-m**, **\--map** *FILE*
>
> > Specify a map file (generated by **nbfc acpi-dump map**) that is
> > used for resolving register names.

**write** \[*OPTIONS*\] *REGISTER* *VALUE*

> Writes *VALUE* to *REGISTER* of the embedded controller.
>
> **-w**, **\--word**
>
> > If given, *VALUE* is written into a combined register of *REGISTER*
> > and *REGISTER + 1*.
>
> **-m**, **\--map** *FILE*
>
> > Specify a map file (generated by **nbfc acpi-dump map**) that is
> > used for resolving register names.

**read_bit** \[*OPTIONS*\] *REGISTER* *BIT-OFFSET*

> Reads the bit at *BIT-OFFSET* from *REGISTER* and prints its value.
>
> *BIT-OFFSET* is the zero-based bit offset (0--7).
>
> **-m**, **\--map** *FILE*
>
> > Specify a map file (generated by **nbfc acpi-dump map**) that is
> > used for resolving register names.

**write_bit** \[*OPTIONS*\] *REGISTER* *BIT-OFFSET* *VALUE*

> Writes *VALUE* to the bit at *BIT-OFFSET* of *REGISTER*.
>
> *BIT-OFFSET* is the zero-based bit offset (0--7).
>
> **-d**, **\--dry**
>
> > If given, shows what would be written without modifying the
> > register.
>
> **-m**, **\--map** *FILE*
>
> > Specify a map file (generated by **nbfc acpi-dump map**) that is
> > used for resolving register names.

**probe** \[*OPTIONS*\] *REGISTER* *VALUES*

> Writes *VALUES* periodically to *REGISTER* while optionally reading
> other registers.
>
> The register\'s original value will be restored afterward.
>
> **NOTE**: This must not be relied upon as a safety mechanism. Writing
> to the wrong register may still cause hardware damage.
>
> Examples for *VALUES*:
>
> > **1** \-- single value
> >
> > **0xFF** \-- single value (hex)
> >
> > **1-100** \-- range of values (step = +1)
> >
> > **100-1** \-- range of values (step = -1)
> >
> > **0-255:5** \-- range of values (step = +5)
> >
> > **255-0:-5** \-- range of values (step = -5)
> >
> > **1-255:\*2** \-- range of values (step = \*2)
> >
> > **0,50,100,255** \-- list of values
> >
> > **0-100,100-0** \-- list of ranges
>
> Presets for *VALUES*:
>
> > **all** \-- 0 - 255
> >
> > **bits** \-- 1, 2, 4, 8, 16, 32, 64, 128
> >
> > **all_reversed** \-- 255 - 0
> >
> > **bits_reversed** \-- 128, 64, 32, 16, 8, 4, 2, 1
>
> **-d**, **\--dry**
>
> > Do not write values to *REGISTER*.
>
> **-m**, **\--map** *FILE*
>
> > Specify a map file (generated by **nbfc acpi-dump map**) that is
> > used for resolving register names.
>
> **-w**, **\--word**
>
> > If given, *VALUES* are written into a combined register of
> > *REGISTER* and *REGISTER + 1*.
>
> **-r**, **\--read** *REGISTER*
>
> > Read and report *REGISTER* during the probe.
>
> **\--read-word** *REGISTER*
>
> > Read and report a 16-bit *REGISTER* during the probe.
>
> **-i**, **\--interval** *SECONDS*
>
> > Specify interval for writing values.
>
> **-t**, **\--timespan** *SECONDS*
>
> > Specify how long the program will run.
>
> The options **\--read** and **\--read-word** can be used up to four
> times.

**monitor** \[*OPTIONS*\]

> Monitor all embedded controller registers for changes.
>
> See **EXAMPLES** for sample output.
>
> **-i**, **\--interval** *SECONDS*
>
> > Sets the update interval in seconds.
>
> **-t**, **\--timespan** *SECONDS*
>
> > Sets how many seconds the program will run.
>
> **-r**, **\--report** *FILE*
>
> > Save the monitored results to a CSV file.
>
> **-c**, **\--clearly**
>
> > With **-r**\|**\--report**: Blanks out consecutive duplicate
> > readings when writing to the CSV file.
>
> **-d**, **\--decimal**
>
> > With **-r**\|**\--report**: Output register readings in decimal
> > format instead of hexadecimal format.
>
> **-C**, **\--cpu**
>
> > Record CPU temperatures.
> >
> > A tool such as **stress** or **stress-ng** should be used to
> > generate CPU load.
>
> **-G**, **\--gpu**
>
> > Record GPU temperatures.
> >
> > A tool such as **stress-ng** should be used to generate GPU load.

**evaluate** \[*OPTIONS*\] *FILE*

> Evaluate a report previously made by **ec_probe monitor \--report
> FILE**.
>
> This command calculates the correlation between register readings and
> CPU/GPU temperature.
>
> Note that the correlation may be reversed, meaning that higher
> register values can correspond to lower temperatures, and vice versa.
>
> The **ec_probe monitor \--report** command must be run with
> **-C**\|**\--cpu** or **-G**\|**\--gpu** or both.
>
> The **ec_probe monitor \--report** command must **not** be run with
> **-c**\|**\--clearly**.
>
> **-d**, **\--decimal**
>
> > Read register values as decimal numbers.

**watch** \[*OPTIONS*\]

> Monitor all embedded controller registers for changes (alternative
> version).
>
> See **EXAMPLES** for sample output.
>
> **-i**, **\--interval** *SECONDS*
>
> > Sets the update interval in seconds.
>
> **-t**, **\--timespan** *SECONDS*
>
> > Sets how many seconds the program will run.

**acpi_call** \[*OPTIONS*\] *METHOD* \[*ARGUMENT*\...\]

> Call an ACPI Method.
>
> The maximum number of arguments is 8.
>
> Example:
>
> > ec_probe acpi_call \'\\\_SB.PCI0.LPCB.EC0.SFSD\' 0xFF
>
> **-d**, **\--dry**
>
> > Print the ACPI command without executing it.
>
> **-m**, **\--map** *FILE*
>
> > Specify a map file (generated by **nbfc acpi-dump map**) that is
> > used for resolving abbreviated method names.

**graph** \[*OPTIONS*\] *FILE*

> Visualize recordings made by **ec_probe monitor \--report**.
>
> The **ec_probe monitor \--report** command must **not** be run with
> **-c**\|**\--clearly**.
>
> **-d**, **\--decimal**
>
> > Read register values as decimal numbers.
>
> **\--register-color** *COLOR*
>
> > Draw the register line in *COLOR* (default: **blue**).
>
> **\--cpu-color** *COLOR*
>
> > Draw the CPU temperature line in *COLOR* (default: **red**).
>
> **\--gpu-color** *COLOR*
>
> > Draw the GPU temperature line in *COLOR* (default: **magenta**).

**lua** *FILE*

> Execute a Lua file.
>
> This command is useful for experimenting with Lua while developing a
> configuration that uses Lua.

**shell**

> Read commands from STDIN.

All input values are interpreted as decimal numbers by default. Use the
\"0x\" prefix for hexadecimal values and \"0b\" for binary values.

# EXIT STATUS

> 0.  Everything fine
>
> 1.  Generic error
>
> 2.  Command-line error
>
> 3.  Initialization error
>
> 4.  Fatal error (memory allocation failure)
